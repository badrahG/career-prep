# CareerPrep Database ERD

## Diagram Title

CareerPrep системийн өгөгдлийн сангийн ерөнхий схем

## Recommended Figure Caption

Зураг X.X. CareerPrep платформын өгөгдлийн сангийн ERD диаграмм

## Short Description For Thesis

CareerPrep платформын өгөгдлийн сан нь `users` хүснэгтийг төв болгон зохион байгуулагдсан. Хэрэглэгч нь CV үүсгэх, ярилцлагын бэлтгэлийн явцаа хадгалах, тэтгэлгийн checklist болон bookmark удирдах, мөн authentication-тэй холбоотой token мэдээллүүдийг эзэмших боломжтой. `cvs` хүснэгт нь `educations`, `work_experiences`, `skills` гэсэн дэд хүснэгтүүдтэй нэг-олон холбоотой. `interview_questions` нь flashcard progress-тэй, `scholarships` нь checklist болон bookmark хүснэгтүүдтэй, харин `advices` нь бие даасан мэдээллийн хүснэгт байдлаар ажиллаж байна. Ийм бүтэц нь карьерын платформын үндсэн функцуудыг өгөгдлийн түвшинд логик байдлаар салгаж, өргөтгөх боломжтой архитектурыг бүрдүүлсэн.

## How To View

3. SVG форматыг ашиглавал хүснэгтийн текст, шугамууд хамгийн цэвэр харагдана.

## Notes

- Энэ ERD нь системийн ерөнхий схем учраас үндсэн хүснэгт, гол FK холбоосуудыг төвлөрүүлж харуулсан.
- Хэрэв хүсвэл дараагийн алхамд би илүү “цэвэр дипломын хувилбар” гаргаж, зөвхөн хамгийн чухал entity-үүдийг үлдээсэн хураангуй ERD бас гаргаж өгч болно.
